光波長怎麼算？λ = c / f 頻率換波長（FM、5G、雷射實例）

Amy · 2026-11-07 · —

收音機轉到 FM 98.1 MHz，空中傳來的電磁波每一個波峰相隔約 3.06 公尺；手機連上 5G 毫米波 28 GHz，波長只剩 10.7 毫米。 兩個數字都來自同一條式子 λ = c / f：光速除以頻率。公式只有一個除號，真正會算錯的是頻率單位的 10 的次方。

λ = c / f
λ 為波長（m）· c 為真空中光速 299,792,458 m/s · f 為頻率（Hz，必須先換成 Hz 再代入）
符號意義單位典型值
λ波長：相鄰兩個波峰的距離m（常換成 cm、mm、nm）FM 電台約 3 m、可見光 400–700 nm
c真空中光速，SI 定義的精確值m/s299,792,458（常近似為 3 × 10⁸）
f頻率：每秒振動次數HzFM 88–108 MHz、Wi-Fi 2.4 / 5 GHz、紅光約 4.7 × 10¹⁴ Hz

為什麼光速除以頻率就是波長？

電磁波每秒振動 f 次，每振動一次往前推進一個波長 λ，所以每秒前進的距離是 f × λ，這個距離就是光速 c。 c = fλ 移項就得到 λ = c / f。它是波速公式 v = fλ 把 v 換成光速的特例： 聲波要看介質裡的聲速，電磁波在真空中一律用同一個 c。

1983 年起，「公尺」由光速定義，c 因此是精確值 299,792,458 m/s，沒有量測誤差。 頻率越高、波長越短，兩者成反比：頻率變 10 倍，波長變成十分之一。

代入前先把頻率換成 Hz：kHz 乘 10³、MHz 乘 10⁶、GHz 乘 10⁹、THz 乘 10¹²。 算出來的 λ 單位是公尺，再依大小換成公分（×100）、毫米（×1,000）或奈米（×10⁹）。

用真實數字算一遍：從 FM 電台到 5G 毫米波

條件：c = 299,792,458 m/s，各頻段代入 λ = c / f：

  1. FM 98.1 MHz：299,792,458 ÷ 98,100,000 ≈ 3.06 m
  2. AM 1,000 kHz（1 MHz）：299,792,458 ÷ 1,000,000 ≈ 299.8 m，比一座足球場還長
  3. GPS L1 訊號 1,575.42 MHz：≈ 19.03 cm
  4. 微波爐 2.45 GHz：≈ 12.24 cm
  5. 台灣 5G 主力頻段 n78 的 3.5 GHz：≈ 8.57 cm
  6. 5G 毫米波 28 GHz：≈ 10.7 mm

28 GHz 的頻率是 98.1 MHz 的約 285 倍，波長就短為約 285 分之一。 波長越短，越容易被牆面、樹葉甚至手掌擋住，這是毫米波基地台要布得很密的物理原因。

天線長度為什麼取四分之一波長？

最常見的單極天線（monopole）長度取 λ/4，在這個長度上電流與電壓分布剛好形成共振，收發效率最好。 所以波長直接決定天線的尺寸：

  • FM 98.1 MHz：3.06 m ÷ 4 ≈ 76.4 cm，接近車用伸縮天線拉到底的長度
  • AM 1 MHz：299.8 m ÷ 4 ≈ 74.9 m，所以 AM 電台的發射塔要蓋幾十公尺高
  • GPS L1：19.03 cm ÷ 4 ≈ 4.76 cm，能塞進手機機身

頻率決定波長、波長決定天線尺寸：手機能做小，前提是它用的是 GHz 等級的頻段。 電路端要產生特定頻率，常用 LC 振盪電路，見LC 共振頻率。

反過來算：雷射波長換成頻率

光學領域習慣報波長（nm），電信與物理計算常需要頻率。同一條式子移項成 f = c / λ，記得先把 nm 換成公尺（×10⁻⁹）：

  • 氦氖紅光雷射 632.8 nm：f = 299,792,458 ÷ (632.8 × 10⁻⁹) ≈ 473.8 THz
  • 綠光雷射筆 532 nm：≈ 563.5 THz
  • 光纖通訊 C 頻段 1,550 nm：≈ 193.4 THz

綠光頻率比紅光高約 19%，每顆光子的能量也跟著高同樣比例，光子能量與頻率的正比關係是普朗克公式 E = hf 的內容。

⚠️ 常見錯誤：MHz 與 GHz 混用，差 1,000 倍

最常見的錯誤是頻率沒換成 Hz，或把 MHz 誤當 GHz。FM 98.1 MHz 若代入 98.1 × 10⁹ Hz，會算出 3.06 mm， 比正確的 3.06 m 小了 1,000 倍；數字長得一樣，只差單位，最不容易被發現。 檢查法是看量級：MHz 對應公尺級、GHz 對應公分級、THz 對應微米到奈米級。 相反地，把 c 近似成 3 × 10⁸ 幾乎不影響結果：相對誤差只有 0.07%，微波爐的 12.24 cm 只差約 0.085 mm。

不在真空裡呢？光纖中的波長會變短

λ = c / f 的 c 是真空光速。光進入折射率 n 的介質後，速度變成 c / n，頻率維持不變，波長跟著縮成 λ / n。 光纖玻璃的折射率約 1.468，光速降為約 2.04 × 10⁸ m/s；1,550 nm 的訊號在纖芯裡的實際波長約 1,056 nm。

規格書上寫的「1,550 nm」一律指真空波長，元件製造與干涉計算才需要介質中的波長。 空氣折射率約 1.0003，對無線電頻段的影響小到可以忽略，所以前面的電台與 5G 實例直接用真空光速。
