向量長度怎麼算？2D 向量大小公式 √(x²+y²) 拆解

Amy · 2026-10-16 · —

往東走 1,200 公尺、再往北走 900 公尺，腳下走了 2,100 公尺， 但起點到終點的直線距離只有 1,500 公尺——中間那 600 公尺 是轉彎吃掉的。算出這條直線的就是向量長度 |v| = √(x² + y²)。 本文拆解 x、y 兩個分量怎麼變成一個長度，並處理最常出錯的那一步： 分量不能直接相加。

|v| = √(x² + y²)
x 水平分量 · y 垂直分量 · |v| 向量長度（又稱大小、模、範數）；平方先消掉負號，開根號再把面積換回長度
符號意義單位典型值
x水平分量：向量在 x 軸上的投影與 y 同單位（公尺、m/s…）任意實數，可負
y垂直分量：向量在 y 軸上的投影與 x 同單位任意實數，可負
|v|向量長度：起點到終點的直線距離與分量同單位恆為非負，零向量時為零

為什麼是平方再開根號，不是 x 加 y？

向量 (x, y) 在座標平面上就是一個直角三角形的斜邊： 底邊長 x、高 y、斜邊就是向量本身。所以這條公式不是新東西， 它是勾股定理 a² + b² = c² 換個寫法， 把 c 單獨解出來而已。

拿最乾淨的例子：v = (3, 4)。先平方，3² = 9、4² = 16， 相加得 25，開根號後 |v| = 5。 走 3 格再走 4 格，直線距離是 5 格而不是 7 格——這個差距就是公式存在的全部理由。

分量可以是負的，長度不行。v = (−8, 15) 代表往西 8、往北 15： (−8)² = 64、15² = 225， 和是 289，|v| = 17。 平方這一步的作用就是消掉負號——方向資訊留在 x、y 各自的正負上， 長度只回答「多遠」，不回答「往哪」。

反過來說，長度相同的向量有無限多個。(3, 4)、(−4, 3)、(5, 0)、(0, 5) 長度全都是 5，因為它們的終點全都落在半徑 5 的圓上， 繞一圈是 2π × 5 = 31.42 個單位長。 |v| 把二維的兩個數壓成一維的一個數，壓縮的代價就是方向被丟掉了。 需要方向就得另外算角度，或改用兩點距離 那樣保留座標的寫法。

用真實數字算一遍：市區兩段位移

場景設定：從捷運站出來，沿街往東走 1,200 公尺，接著往北走 900 公尺到第一個客戶。 把這段路當成向量 a = (1200, 900)，x 軸朝東、y 軸朝北，單位公尺。

直線距離 |a| = √(1200² + 900²) = √2250000 = 1,500 公尺。 但腳實際踩過的街道長度是 1,200 + 900 = 2,100 公尺， 兩者差 600 公尺，等於多走了 40%。 街廓越方正、兩段距離越接近，這個差距越大；完全同方向時才會相等。

接著第二段：往西 400 公尺、往北 300 公尺到第二個客戶， 也就是 b = (−400, 300)，長度 |b| = √((−400)² + 300²) = 500 公尺。 注意這裡的西向用負號記在 x，而不是另外記一個「方向欄位」—— 有正負號，向量才能直接相加。

兩段合起來的總位移是 a + b = (1200 − 400, 900 + 300) = (800, 1,200)， 長度 √(800² + 1200²) = 1,442.22 公尺。 而兩段直線距離加總是 1,500 + 500 = 2,000 公尺。 路程會相加，位移不會：中間差的 557.78 公尺 是第二段往回走的那 400 公尺折抵掉的。 先把分量加完再開根號，和先各自開根號再相加，是兩個不同的問題。

單位向量、方向角與 |v|² 的用處

把向量除以自己的長度，就得到長度為 1 的單位向量。 v = (3, 4) 除以 5 得 (0.6, 0.8)， 驗算 0.6² + 0.8² = 1，確實是單位長度。 這一步叫正規化，用途是「只要方向、不要大小」： 地圖上的指向箭頭、物理模擬裡的受力方向、 機器學習把特徵向量拉到同一尺度，用的都是這個除法。

長度配上方向角才算完整描述。方向角 θ = atan(y ÷ x)， v = (3, 4) 的 θ = 53.13 度（從 x 軸正向逆時針量）。 長度與角度這組極座標寫法，和 (x, y) 這組直角座標寫法，資訊量完全相同， 只是哪一個算起來方便的差別。

換個領域，公式一字不改。一架無人機水平飛 12 m/s、同時爬升 5 m/s， 實際速率 √(12² + 5²) = 13 m/s， 爬升角 atan(5 ÷ 12) = 22.62 度。 儀表上那兩個分量讀數都不是真實速率，合成後才是。

最後一個實務細節：很多時候根本不需要開根號。 動能 ½mv² 要的是速率的平方， 而 |v|² = x² + y² = 169，開根號再平方等於白做。 機體質量 1.2 公斤時，動能 ½ × 1.2 × 169 = 101.4 焦耳。 比較兩個向量誰長、找最近的點、判斷是否進入半徑範圍， 一律可以直接比 x² + y²——省下開根號，結果完全一樣。

⚠️ 常見錯誤

把分量直接相加。v = (−8, 15) 的長度不是 8 + 15 = 23， 是 17，直接相加會高估 35.29%。 兩個分量越接近，高估越嚴重；只有其中一個為零時兩種算法才一致。 第二個常錯的是把負號帶進平方：(−8)² 是 64 不是 −64， 代成 −64 + 225 會得到 12.69，比正確的 17 還小—— 長度算出來比任何一個分量的絕對值（這裡是 15）還小，就一定是這個錯。 第三個是忘記開根號，把 289 當成答案； 單位是判斷依據：x² + y² 的單位是公尺平方，長度必須是公尺。

二維向量 v = (x, y) 的長度（magnitude、模、歐幾里得範數 ‖v‖₂）定義為 √(x² + y²)， 即內積 v·v 的平方根；三維為 √(x² + y² + z²)，n 維同理逐項平方後開根號。 長度恆為非負，等於零若且唯若 x = y = 0。方向角 θ = atan2(y, x)， 本文實例皆取 x > 0 的第一象限，故可直接寫成 atan(y ÷ x)。 文中距離、速度、質量皆為假設值，僅作數學說明。 全文數字均經 scripts/verify_formula_math.py 獨立驗算。
