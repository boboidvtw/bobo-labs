氫原子能階怎麼算？波耳模型 E = −13.6/n² 公式拆解（紅光實例）

Amy · 2026-11-05 · —

氫原子的電子從第 3 能階掉到第 2 能階，會放出一顆能量 1.89 eV 的光子，波長 656.4 nm，是可見紅光。 數字來自波耳模型 Eₙ = −13.6 eV / n²。公式只有一個除法，會算錯的是負號、n 的平方，以及能階和能階差的分別。

Eₙ = −13.6 eV / n²
Eₙ 為氫原子第 n 能階的電子能量（eV）· 13.6 eV 為氫原子基態束縛能（Rydberg 能量）· n 為主量子數（1, 2, 3, …）
符號意義單位典型值
Eₙ第 n 能階的電子總能量eV（1 eV = 1.602×10⁻¹⁹ J）基態 −13.6 eV，n = 2 為 −3.4 eV
n主量子數，只能取正整數無因次1（基態）、2、3…；可見光譜線涉及 n = 2–6
13.6Rydberg 能量，氫原子基態的束縛能eV常用 13.6
hc普朗克常數 × 光速，用來把 eV 換成波長eV·nm1239.84

為什麼能量是負的？先看各能階的數字

波耳模型把「電子離核無窮遠、靜止」定為 0 eV。被原子核吸住的電子要外加能量才拉得走，所以束縛態都低於 0。代入 n = 1 到 6：

  • n = 1：−13.6 ÷ 1 = −13.6 eV（基態）
  • n = 2：−13.6 ÷ 4 = −3.4 eV
  • n = 3：−13.6 ÷ 9 ≈ −1.51 eV
  • n = 4：−13.6 ÷ 16 = −0.85 eV
  • n = 5：−13.6 ÷ 25 = −0.544 eV
  • n = 6：−13.6 ÷ 36 ≈ −0.378 eV

n 越大，能量越接近 0，相鄰能階的間距也越小：n = 1 到 2 差 10.2 eV，n = 5 到 6 只差約 0.17 eV。 能階越往上越密集，最後在 0 eV 匯成連續區，電子脫離原子，也就是游離。

用真實數字算一遍：n = 3 掉到 n = 2 放出什麼光？

條件：氫原子電子從 n = 3 躍遷到 n = 2，求光子能量與波長：

  1. 能階差：ΔE = E₃ − E₂ = 13.6 × (1/2² − 1/3²) = 13.6 × (1/4 − 1/9) = 1.89 eV
  2. 換成焦耳：ΔE × 1.602×10⁻¹⁹ J/eV ≈ 3.026 × 10⁻¹⁹ J
  3. 換成波長：λ = hc / ΔE = 1239.84 ÷ (13.6 × 5/36) ≈ 656.4 nm
  4. 換成頻率：f = ΔE / h = ΔE ÷ (4.1357×10⁻¹⁵ eV·s) ≈ 4.567 × 10¹⁴ Hz

656.4 nm 是可見紅光，天文學稱為 Hα 線。 用波速公式 v = fλ 交叉檢查：2.998×10⁸ m/s ÷ 656.4 nm 同樣得到約 4.567 × 10¹⁴ Hz。

巴耳末系：氫原子的四條可見光譜線

掉回 n = 2 的躍遷合稱巴耳末系（Balmer series），其中四條是可見光：

  • n = 3 → 2：ΔE = 1.89 eV，λ ≈ 656.4 nm（紅）
  • n = 4 → 2：ΔE = 13.6 × (1/4 − 1/16) = 2.55 eV，λ = 1239.84 ÷ 2.55 ≈ 486.2 nm（藍綠）
  • n = 5 → 2：ΔE = 13.6 × (1/4 − 1/25) = 2.856 eV，λ ≈ 434.1 nm（藍紫）
  • n = 6 → 2：ΔE = 13.6 × (1/4 − 1/36) ≈ 3.022 eV，λ ≈ 410.2 nm（紫）

起點越高，波長越短、間隔越擠，最後收斂到 n = 2 游離的極限： 1239.84 ÷ 3.4 ≈ 364.7 nm，已進入紫外線。掉回 n = 1 的萊曼系能量更大， 最弱的 n = 2 → 1 就有 10.2 eV，λ ≈ 121.6 nm，全在紫外線。

游離能與類氫離子：13.6 eV 從哪裡用到？

把基態電子整個拉走，需要從 −13.6 eV 補到 0，也就是 13.6 eV，這就是氫原子的游離能。 能做到這件事的光子波長上限是 1239.84 ÷ 13.6 ≈ 91.2 nm，比這更長的光無論多強都游離不了基態氫。

只有一個電子的離子（He⁺、Li²⁺）也能套用，但原子核電荷變成 Z 倍，公式改為 Eₙ = −13.6 Z² / n² eV。 He⁺ 的 Z = 2，基態能量是 −13.6 × 4 = −54.4 eV。

⚠️ 常見錯誤：忘了平方、拿單一能階算波長

第一種錯誤是把 n² 寫成 n：n = 3 會算出 −13.6 ÷ 3 = −4.53 eV，正確值是 −1.51 eV； 同樣錯法下 3 → 2 的能階差變成 13.6 × (1/2 − 1/3) = 2.27 eV，波長 547.0 nm，紅光被算成綠光。 第二種錯誤是直接拿 E₃ 的 1.51 eV 換波長，得到 1239.84 ÷ (13.6/9) ≈ 820.5 nm 的紅外線—— 那是「從 n = 3 游離」所需的光，不是躍遷放出的光。光子能量永遠是兩個能階的差，取絕對值計算。

波耳模型什麼時候不準？

13.6 eV 假設原子核質量無限大；考慮質子質量修正後，氫的實測游離能是 13.598 eV，相差約 0.015%。 模型的邊界有三個：只適用單電子系統；解釋不了譜線在高解析度下分裂（精細結構）；算不出譜線亮度比。 做光譜辨識與能階估算，波耳公式已經夠用。
